# Lab 06 – Intelligent University Assistant

## Overview

This laboratory explores the development of an Intelligent University Assistant through two implementation approaches. The project investigates the development of AI-powered assistants using a programmatic Python approach and a visual workflow automation approach.

## Implementation Methods

### Method 01 – Python-Based Implementation

This approach focuses on building an AI assistant programmatically using Python, integrating tools, memory, university-related data and other functionalities.

Implementation details, source code, notebooks and evidence are maintained in the `Method_01_Python` directory.

### Method 02 – Visual Workflow-Based Implementation Using n8n

This approach explores the development of an Intelligent University Assistant using n8n, Ollama, conversational memory and external integrations.

The assistant is developed using a visual workflow and integrated with Google Calendar and Gmail.

Implementation details, workflow exports, documentation and evidence are maintained in the `Method_02_n8n` directory.

## Repository Structure

| Directory | Description |
|---|---|
| `Method_01_Python` | Python-based implementation |
| `Method_02_n8n` | n8n-based implementation |
| `comparison` | Comparison of the two approaches |

## Objectives

- Explore different approaches to developing AI agents.
- Implement an AI assistant using Python.
- Implement an AI assistant using visual workflow automation.
- Explore LLM integration, memory and tool usage.
- Integrate external services.
- Compare the two implementation approaches.

## Progress

The laboratory implementations are being developed incrementally. Individual implementation details and evidence are maintained within their respective directories.
